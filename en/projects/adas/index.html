Camera-based ADAS

Lane departure & forward collision warning on Jetson Nano

Mar 2022 – Jun 2022 · Course project

ADAS Object Detection OpenCV Jetson

Background

  • Build ADAS functions from a single camera, without extra sensors
  • Run detection and image processing in real time on Jetson Nano

Approach

  • OpenCV lane detection (HSV, ROI, HoughLinesP) and lane-departure warning
  • Vehicle detection with YOLOv3-tiny and forward-risk warning logic
  • Integrated the pipeline on Jetson Nano

Results

  • ~23 FPS object detection on Jetson Nano
  • Lane departure warning (LDW) and forward vehicle warning
  • End-to-end camera-based ADAS prototype

My Role

  • Lane detection and LDW algorithm
  • C++/OpenCV system integration and edge validation
