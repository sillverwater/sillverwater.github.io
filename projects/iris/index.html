Edge Device(NPU) 환경을 위한 실시간 홍채 인식 시스템

2024.05 - 2024.08

Computer VisionOn-Device AIImage SegmentationIris Recognition

연구 배경

  • 홍채 인식 모델을 Edge Device에서 실시간으로 구동하기 위한 최적화 필요
  • Segmentation과 Iris Code를 결합한 Hybrid 인식 시스템 개발

진행 과정

  • 홍채·동공·눈꺼풀 영역 라벨링 및 YOLOv8s 기반 Segmentation 모델 개발
  • 속눈썹 제거, Iris Code 추출, Hamming Distance 기반 식별 구현
  • Jetson Nano 및 Mythic NPU 환경에서 모델 최적화와 성능 검증

성과

  • Segmentation 모델 평균 IoU 0.96
  • NPU에서 전체 시스템 평균 처리시간 47 ms (21 FPS)
  • Edge Device에서도 높은 성능을 확보한 Hybrid 홍채 인식 시스템 구현
  • 국제 학술대회(ICGHIT 2025) Oral Session 발표

기여도

  • 데이터셋 구축, 홍채 Segmentation 모델 개발, NPU 검증
  • 논문 작성 및 학술대회 발표
