<div class="ey-section"><h2>Background</h2>
<ul>
  <li>Automating vasculature assessment that relied on visual inspection with AI</li>
  <li>Achieving both accuracy and real-time performance for Edge Device deployment</li>
</ul>
</div>

<div class="ey-section"><h2>Process</h2>
<ul>
  <li>Built an organoid vasculature image dataset and addressed class imbalance</li>
  <li>Developed a lightweight EfficientNet-based normal/abnormal classification model</li>
  <li>NVIDIA Jetson Nano: FP16 optimization, FuriosaAI Warboy NPU: INT8 quantization, performance validation</li>
</ul>
</div>

<div class="ey-section"><h2>Results</h2>
<ul>
  <li>40% smaller model size</li>
  <li>99% accuracy maintained on NPU, 31% lower inference latency</li>
  <li>Demonstrated automated vasculature assessment and on-device applicability</li>
  <li>Published as first author in an SCIE journal (Sensors)</li>
</ul>
</div>

<div class="ey-section"><h2>Contribution</h2>
<ul>
  <li>Led the entire study - dataset construction, model design and compression, NPU validation</li>
  <li>Paper writing</li>
</ul>
</div>
